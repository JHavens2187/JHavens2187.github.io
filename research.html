Constraining Dust Attenuation in Star Forming Galaxies

Breaking the fundamental degeneracy between dust content and attenuation slope ($k(\lambda)$) in Active Galactic Nuclei using multi-line diagnostics.

INSTRUMENTATION & TOOLS
JWST / NIRSpec Chandra / ACIS Python LMFIT ICARUS Pipeline

The Physics Problem

The standard method for estimating dust attenuation (the Balmer Decrement) is fundamentally degenerate. It can only solve for the normalization ($E(B-V)$) if the slope of the attenuation curve ($k(\lambda)$) is assumed, or vice versa.

The Methodology: This research utilizes Chandra X-ray data to definitively select and isolate AGN from the broader galaxy population. Once isolated, we break the dust degeneracy by combining Hydrogen Balmer and Paschen lines from JWST/NIRSpec, allowing us to simultaneously derive both the specific dust content and the attenuation law unique to the complex AGN environment.

The Engine: ICARUS

ICARUS (Integrated Cosmic Analysis Research Utility for Spectroscopy) is a specialized, proprietary suite developed for high-precision AGN spectral decomposition, building upon the core logic of the GLEAM pipeline.

Core Capabilities & Benchmarks:

  • Kinematic Selection: Automated $\chi^2$ comparison to select between Broad Line (BL), Narrow Line (NL), and Blended line profiles.
  • Numerical Accuracy: Verified sub-5% error on flux and line-width measurements across an SNR range of 2–10.
  • Detection Logic: Integrated RandomVariable class for rigorous error propagation and automated $3\sigma$ thresholding.
kinematics_engine.py (Model Selection) 
def select_optimal_model(self, nl_fit, bl_fit, threshold=0.15):
    """
    ICARUS Decision Engine: Compares Reduced Chi-Squared values to 
    determine if the addition of a Broad Line component is statistically 
    significant or merely over-fitting.
    """
    improvement = (nl_fit.redchi - bl_fit.redchi) / nl_fit.redchi

    if improvement > threshold and bl_fit.params['sigma_broad'].value > self.inst_res:
        self.logger.info(f"Broad Line detected: {improvement:.2%} improvement")
        return bl_fit
    
    return nl_fit
