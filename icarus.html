The ICARUS Pipeline

Integrated Cosmic Analysis Research Utility for Spectroscopy. A comprehensive numerical orchestration engine designed for automated kinematic selection and high-fidelity emission line fitting.

Ingestion & Dynamic Scaling

ICARUS standardizes chaotic input data through an immutable `Spectrum1D` container. To protect the optimization algorithms from the inherent limitations of floating-point precision, the ingestion engine dynamically normalizes spectral arrays.

Array Normalization

The pipeline computes a dynamic scale factor for each unique spectrum, standardizing flux values to $O(1)$ space using $10^{\lfloor\log_{10}(\text{median flux})\rfloor}$. This explicitly prevents optimizer crashes when processing faint high-redshift targets with raw fluxes on the order of $10^{-19}$ erg s$^{-1}$ cm$^{-2}$ $\text{\AA}^{-1}$. The true physical units are mathematically restored during the final astrophysical yield compilation.

Cosmological Projection

Relying on an underlying `FlatLambdaCDM` cosmology model, raw observational vectors are cleanly projected and de-redshifted into strict rest-frame coordinates.

The Kinematic Decision Engine

The core logic of ICARUS evaluates complex, multi-component line structures to identify energetic outflows and Active Galactic Nuclei (AGN). The pipeline dynamically tests standard narrow-line emission against multi-component broad-line models.

  • Statistical Auditing: The addition of a broad-line component must survive a strict Bayesian Information Criterion ( $\Delta\text{BIC}$ ) test, ensuring kinematic complexity is statistically significant rather than mere over-fitting.
  • Quantum Doublet Tying: Algebraic constraints physically lock emission doublets. The [O III] $\lambda5007/\lambda4959$ complex is rigidly tied to a 1:2.98 amplitude ratio, while the [N II] $\lambda6583/\lambda6548$ complex is locked to 1:2.95.
  • Kinematic Outflow Shifts: In composite systems, the kinematic velocity shifts of broad secondary lines are mathematically forced to match their primary pair, drastically reducing the optimizer's parameter space.

Hierarchical Plotting & Analysis

ICARUS enforces a strict visual geometry standard. It suppresses raw spectral arrays and background integration windows to muted, semi-transparent base layers (e.g., slate gray), deliberately elevating the analytical curves and dynamic multi-component fits with high-contrast, high-zorder properties.

Calculated Astrophysics:

Upon successful convergence, the engine calculates key physical parameters including Virial Black Hole Mass ($\log_{10}(M_{BH}/M_\odot)$), Uncorrected Star Formation Rates (using equivalent base traces like H$\alpha$ or Pa$\beta$), and local RMS boxcar measurements to derive 3-$\sigma$ upper limits for non-detections (denoted visually by $\downarrow$).

The Middleware Debugging Engine

The @dev_hook architectural pattern embeds a non-destructive event emitter and Directed Acyclic Graph (DAG) registry throughout the pipeline. This allows developers to pass a .dev telemetry configuration file to inject synthetic data, force algorithmic failures, trace memory usage, or actively bypass standard multiprocessing for interactive terminal shell pauses—all without altering production code.
